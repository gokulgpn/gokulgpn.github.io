Supervised land-cover classification of Munich

Mapping urban land, bare or open land, water and vegetation from a summer Sentinel-2 composite using Random Forest.

Sentinel-2 L2ARandom ForestGoogle Earth EngineRemote sensing

PROJECT OVERVIEW

ObjectiveMap comparisonMethodAccuracyInterpretationLimitations

Objective

This project tests a transparent, four-class land-cover workflow for Munich: urban / built-up, bare / open land, water and vegetation. The goal is a concise, reproducible remote-sensing exercise rather than a production land-cover product.

Data. Sentinel-2 Level-2A surface reflectance from summer 2026, cloud-screened with Cloud Score+ and aggregated as a summer median composite. The predictor stack combines B2, B3, B4, B8, B11, B12, NDVI and MNDWI.

RGB composite and classified map

The comparison below presents the supplied Earth Engine outputs with a portfolio-ready legend. The RGB source capture includes the manually labelled sample overlay; it has not been replaced with invented imagery.

Method

Four manually labelled classes were sampled with 100 points each (400 samples before masking). A random 70% / 30% split from that same labelled sample set was used for model fitting and testing. The classifier used 100 trees and a random seed of 42.

Interpretation

Urban and bare / open land show the strongest reciprocal confusion, which is plausible where impervious surfaces, construction sites and exposed soils have similar spectral responses. Water and vegetation are more reliably separated. Fine-grained salt-and-pepper variation remains visible because this is a pixel-based classification without post-classification smoothing.

Limitations and tools

The reported test accuracy is specific to the random holdout split drawn from the same manually labelled sample set. It should not be read as a spatially independent accuracy estimate. A stricter production validation would use geographically separate reference samples, ideally supported by independent imagery or field data.
